# Groep-SD
🔴SkillRadar

SkillRadar is een webapplicatie waarmee gebruikers hun persoonlijke vaardigheden kunnen beoordelen en visualiseren in de vorm van een radar chart (vaardighedenroos).
Gebruikers kunnen zelf labels (vaardigheden) toevoegen, waarden invoeren, en hun resultaten opslaan in een database om later terug te zien op het dashboard.
-------------------------------------------------------------------------------------------

🔴Functies

Dynamisch toevoegen en aanpassen van labels

Invoeren van waardes (1–10) voor elke vaardigheid

Automatische weergave van een interactieve radar chart

Opslaan van meerdere radars in een MySQL-database

Overzicht van opgeslagen radars op het dashboard
-------------------------------------------------------------------------------------------

🔴Gebruikte technologieën

HTML, CSS, JavaScript – frontend

Chart.js – radarvisualisatie

PHP & MySQL – backend en dataopslag
